# Sound credits

"Real recordings" mode uses short loops derived from the freely licensed recordings below.
**Changes made:** short segments were cut out, time-warped so each loop holds a steady pitch (one engine RPM), high-passed, loudness-normalised, converted to mono AAC (`sounds/*.m4a`) and crossfaded into loops in the browser.
The derived loops in `sounds/` are released under the same licence as their source recording (CC BY-SA sources stay CC BY-SA; the CC BY 4.0 source stays CC BY 4.0).
